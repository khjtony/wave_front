These files are the registered claims G1 to G25 from `docs/agi_testbed.md` section 5, registered before any AGI guard (G1 to G22 on 2026-10-17, G23 to G25 on 2026-11-09 from `docs/ww2_si_disanalogies.md`).
Since the model step of 2026-11-10 (`models/agi/v0.py`) each testable claim has a body behind the decorator `first_sight` (`tests/agi/common.py`): it is skipped unless `WF_FIRST_SIGHT_AGI=1`, because one pass is hours of kernels. G9, G10, G20 and G22 stay stubs with the reason "not yet testable" (v1 elements, or a second dated snapshot).
To run: `python -m tests.agi.jobs` computes and caches the fixpoints the claims list as `JOBS` (budgets in `docs/agi_v0_decisions.md` section 2), then `WF_FIRST_SIGHT_AGI=1 pytest tests/agi/scenarios/test_GNN.py -s`, one process per file. The first such run is the first sight; its commit is recorded in `tests/agi/test_model_agi.py` as `FIRST_SIGHT_COMMIT` and in `docs/guard_changelog_agi.md`, and the hold-out results stand as first computed.
Do not edit the claim text without a changelog entry (section 9 of `docs/agi_testbed.md`); `tests/agi/test_registration.py` checks the files against the document and that each stays skipped by default until first sight is recorded.
