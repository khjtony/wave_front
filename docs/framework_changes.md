# Framework changes

The log of changes to the `wavefront` framework (the contract in [framework_spec.md](framework_spec.md)) made after the phase 2 gate. [PHASES.md](PHASES.md) phase 3 and [validity.md](validity.md) C5 set the budget: at most five logged framework changes during the Cold War phase, each episode-agnostic (a change whose rationale names a historical episode is a domain-model change, not a framework change), each naming what forces it and rerunning the WW2 suite. Phase 4's framework diff (PLAN.md step 4.1) is built from this table.

Columns: the date; the change's name; what changed, with the spec sections; the forcing need (the test or modelling need that requires it; episodes may be named here); the rationale, which must not name an episode; the WW2 suite rerun after the change.

| 2026-10-15 | Per-actor decision cadence | `m.actor(name, cadence=k)`, k ≥ 1, default 1 (spec 3.1, 3.1a, 3.4, 4, 6, 9, 15; theory.md 1.1, 1.2). With k ≥ 2 the built-in counter `cadence_<actor>` in `0..k-1` is added after every other built-in; the actor's declared actions are available only when it is 0, `idle` always; a declared action sets it to k-1, anything else decrements it to 0. A binding fairness restriction overrides the counter (its responses are available whatever the counter says) and a declared response resets it. Delays and profiles unchanged. Implemented in the compiler, the bounded (Z3) encoder and the symbolic (BDD) encoder; snapshots may set `cadence_<actor>`; `V.only` includes the actor's own counter; `budget()` gains the key `cadence`; `fingerprint` covers cadences only when one is used. k = 1 adds no variable: the toy and WW2 v0/v1 models compile to the same layout, assumptions and fingerprints as before (the budget gains `cadence: 0`). Tests: `tests/model/test_model_cadence.py`, cadence cases in `tests/bmc/test_bmc_semantics.py`, cadenced rich models in the BMC and symbolic cross-checks (with a sweep in which every model has a cadence and the fairness override occurs), the toy `models/toy/cadence.py` with `tests/toy/test_cadence.py`. | No registered test yet. Modelling needs: asymmetric decision speed in the July 1914 crisis (mobilization timetables against cabinet decisions), the AGI model's fast automated actor against slow institutions, and the Cold War crisis sub-games at daily ticks, where governments do not decide every day. | When actors decide at rates that differ by an integer factor, a single tick length either lets the slow actor decide as often as the fast one, overstating its tempo, or coarsens the tick and hides the fast actor's intermediate steps. A per-actor refractory period, kept as a bounded built-in counter like the delay and fairness counters, expresses the difference without changing the tick, keeps the game finite and memoryless, and leaves every model without a cadence unchanged. Bounded fairness keeps precedence because it encodes an obligation to respond, which a decision period should not suspend. | `tests/ww2 -m "not slow"`: the whole repository's non-slow selection after the change: 844 passed, 28 skipped, 85 deselected (5 min 26 s); the v0 and v1 fingerprints are unchanged (checked against the pre-change commit 7e533d4: v0 b43a8993ea82, v1 420a12c0e1cf). | 2026-10-27 | Sets of levels in snapshots (robust and fragile findings) | A snapshot variable may give `levels: [{level, confidence, indicators}, ...]` with `ambiguity` instead of one `level` (schema `$defs.variable_set`; mutually exclusive with `level`; at least two members, each with its own provenance; built-ins stay single-valued). The replay metrics (WW2 and Cold War) count a replayed level in a set-valued hindsight level as agreeing, report those quarters separately (`Metrics.ambiguous`), date a documented flip across a window by the window (`Flip.window_end`) and list replayed flips inside a window apart from false flips (`Metrics.window_flips`). No engine change; no domain snapshot uses a set. Spec 7, 8, 9, 10; design in docs/ambiguous_levels.md. Tests: tests/evidence/test_ambiguous_levels.py (schema and validator incl. a jsonschema mutation corpus, product sets, latches per member, refusals, replay metrics, and every committed snapshot loading to exactly the state pinned with the pre-change loader, tests/evidence/fixtures/snapshot_states_pin.json), tests/analysis/test_robust.py (a toy game with a known fragile kernel and blocking coalition, the report and the CLI). | Owner's decision of 2026-10-27. Carrying the set of defensible levels, each with its own evidence, and asking every question from each member separates the findings that do not depend on the choice from those that do, and names the readings on which the latter turn.
