# Framework changes

The log of changes to the `wavefront` framework (the contract in [framework_spec.md](framework_spec.md)) made after the phase 2 gate. [PHASES.md](PHASES.md) phase 3 and [validity.md](validity.md) C5 set the budget: at most five logged framework changes during the Cold War phase, each episode-agnostic (a change whose rationale names a historical episode is a domain-model change, not a framework change), each naming what forces it and rerunning the WW2 suite. Phase 4's framework diff (PLAN.md step 4.1) is built from this table.

Columns: the date; the change's name; what changed, with the spec sections; the forcing need (the test or modelling need that requires it; episodes may be named here); the rationale, which must not name an episode; the WW2 suite rerun after the change.

| Date | Name | What changed | Forcing need | Episode-agnostic rationale | WW2 suite rerun |
|---|---|---|---|---|---|
| 2026-10-15 | Per-actor decision cadence | `m.actor(name, cadence=k)`, k ≥ 1, default 1 (spec 3.1, 3.1a, 3.4, 4, 6, 9, 15; theory.md 1.1, 1.2). With k ≥ 2 the built-in counter `cadence_<actor>` in `0..k-1` is added after every other built-in; the actor's declared actions are available only when it is 0, `idle` always; a declared action sets it to k-1, anything else decrements it to 0. A binding fairness restriction overrides the counter (its responses are available whatever the counter says) and a declared response resets it. Delays and profiles unchanged. Implemented in the compiler, the bounded (Z3) encoder and the symbolic (BDD) encoder; snapshots may set `cadence_<actor>`; `V.only` includes the actor's own counter; `budget()` gains the key `cadence`; `fingerprint` covers cadences only when one is used. k = 1 adds no variable: the toy and WW2 v0/v1 models compile to the same layout, assumptions and fingerprints as before (the budget gains `cadence: 0`). Tests: `tests/model/test_model_cadence.py`, cadence cases in `tests/bmc/test_bmc_semantics.py`, cadenced rich models in the BMC and symbolic cross-checks (with a sweep in which every model has a cadence and the fairness override occurs), the toy `models/toy/cadence.py` with `tests/toy/test_cadence.py`. | No registered test yet. Modelling needs: asymmetric decision speed in the July 1914 crisis (mobilization timetables against cabinet decisions), the AGI model's fast automated actor against slow institutions, and the Cold War crisis sub-games at daily ticks, where governments do not decide every day. | When actors decide at rates that differ by an integer factor, a single tick length either lets the slow actor decide as often as the fast one, overstating its tempo, or coarsens the tick and hides the fast actor's intermediate steps. A per-actor refractory period, kept as a bounded built-in counter like the delay and fairness counters, expresses the difference without changing the tick, keeps the game finite and memoryless, and leaves every model without a cadence unchanged. Bounded fairness keeps precedence because it encodes an obligation to respond, which a decision period should not suspend. | `tests/ww2 -m "not slow"`: the whole repository's non-slow selection after the change: 844 passed, 28 skipped, 85 deselected (5 min 26 s); the v0 and v1 fingerprints are unchanged (checked against the pre-change commit 7e533d4: v0 b43a8993ea82, v1 420a12c0e1cf). The full slow WW2 suite (about two hours) was not run, because other agents were using the machine; the change adds no variable to WW2 v0/v1 and their layouts, assumptions and fingerprints are unchanged. Framework suites (`tests/model tests/bmc tests/symbolic tests/engine tests/analysis tests/evidence tests/cli tests/viz tests/toy tests/report`): tests/model, bmc, engine, toy and analysis with their slow tests: 362 passed (2 min 18 s); tests/symbolic without the slow WW2 states: 18 passed; tests/evidence and cli: 334 passed; viz and report inside the non-slow selection. |

Note on the first row: the change was made before any Cold War test (C1 to C13) was run, at the architect's request, ahead of the 1914 and AGI models; whether it counts against the phase 3 budget is the owner's decision.

Phase 3, Cold War v0 (2026-10-17): no framework change was made; the crisis machinery, the symbolic engine and the analysis layer were used as specified, and the lifting, the bounded cut-off and the restricted games are analysis devices in tests/coldwar/common.py (docs/cw_v0_decisions.md D5, D9). Budget used: 0 of 5 (or 1 of 5 if the owner counts the cadence above).
